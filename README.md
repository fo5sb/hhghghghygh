# 🌴 نظام المَذْخُورَة لإدارة فواتير استلام التمور

نظام إلكتروني متكامل لإدارة فواتير واستلام ومعالجة التمور، مبني بتقنية Progressive Web App (PWA) يعمل على جميع الأجهزة والمتصفحات.

---

## ✨ مميزات النظام

- 📝 إنشاء وحفظ فواتير استلام التمور بسهولة
- 📋 سجل كامل للفواتير مع البحث والفلترة المتقدمة
- 📊 لوحة إحصائيات ومؤشرات تفاعلية
- 🖨️ طباعة الفواتير بتصميم يطابق الورقة الأصلية
- 💾 حفظ دائم للبيانات محلياً على كل جهاز (IndexedDB)
- ☁️ دعم المزامنة السحابية عبر Supabase (اختياري)
- 📱 يعمل كتطبيق جوال (PWA) قابل للتثبيت
- 🔒 رمز PIN لحماية الحذف ومسح البيانات

---

## 🚀 رفع الموقع على GitHub Pages (مجاناً)

### الخطوة 1: إنشاء حساب GitHub
1. اذهب إلى [github.com](https://github.com) وأنشئ حساباً مجانياً إذا لم يكن لديك واحد.

### الخطوة 2: إنشاء Repository جديد
1. اضغط على زر **"New"** أو **"+"** في أعلى الصفحة.
2. سمّ المستودع: `almadkhoorah` (أو أي اسم تريده بالإنجليزية بدون مسافات).
3. اجعله **Public** (عام) - هذا مطلوب لـ GitHub Pages المجاني.
4. **لا تضف** أي ملفات أولية (لا README, لا .gitignore).
5. اضغط **"Create repository"**.

### الخطوة 3: رفع ملفات الموقع
**الطريقة الأسهل (عبر المتصفح مباشرة):**
1. في صفحة المستودع الفارغة، اضغط على **"uploading an existing file"**.
2. اسحب وأفلت **جميع ملفات المجلد** (index.html, css/, js/, icons/, manifest.json, sw.js).
   - **ملاحظة:** لا ترفع ملفات: `server.js`, `server.py`, `server.ps1`, `تشغيل_النظام.bat`, `تشغيل_كموقع_محلي.bat` - هذه للاستخدام المحلي فقط.
3. اكتب رسالة commit مثل: `رفع نظام المذخورة`
4. اضغط **"Commit changes"**.

> **ملاحظة:** عند رفع مجلدات (css, js, icons)، GitHub لا يسمح برفعها مباشرةً بالسحب والإفلات إذا كانت مجلدات. استخدم الطريقة التالية:
> - ارفع الملفات داخل كل مجلد بشكل منفصل مع كتابة المسار يدوياً، مثلاً: `css/style.css`
> - أو استخدم GitHub Desktop (انظر الخيار B أدناه).

**الخيار B - باستخدام GitHub Desktop (أسهل للمجلدات):**
1. حمّل [GitHub Desktop](https://desktop.github.com/) وثبّته.
2. سجّل دخولك بحساب GitHub.
3. اضغط **"Clone a repository"** واختر المستودع الذي أنشأته.
4. انسخ جميع ملفات المشروع إلى المجلد الذي clone فيه المستودع.
5. في GitHub Desktop، ستظهر جميع الملفات، اضغط **"Commit to main"** ثم **"Push origin"**.

### الخطوة 4: تفعيل GitHub Pages
1. في صفحة المستودع، اذهب إلى **Settings** (الإعدادات).
2. من القائمة الجانبية اختر **Pages**.
3. تحت **"Branch"**، اختر `main` ثم اختر `/` (root).
4. اضغط **Save**.
5. انتظر دقيقة أو دقيقتين، ثم سيظهر رابط موقعك مثل:
   ```
   https://USERNAME.github.io/almadkhoorah/
   ```

### الخطوة 5: مشاركة الرابط 🎉
- أرسل الرابط لأي شخص ليستخدم النظام من أي جهاز وأي مكان!
- كل مستخدم يحتفظ ببياناته محلياً على جهازه.

## ☁️ المزامنة السحابية (اختياري - لاستخدام أكثر من شخص)

إذا أردت مشاركة البيانات بين أجهزة ومستخدمين مختلفين:
1. أنشئ حساباً مجانياً على [supabase.com](https://supabase.com)
2. أنشئ مشروعاً جديداً
3. في النظام، اذهب إلى **الإعدادات والنسخ** ثم قسم **Supabase**
4. اتبع التعليمات الموضحة في الصفحة
