☁️ الربط والمزامنة السحابية (Supabase)
○ قاعدة بيانات محلية

يتيح الربط مع Supabase مشاركة ومزامنة فواتير المذخورة بين الموظفين والأجهزة المختلفة (الكمبيوتر، الجوال، التابلت) في الوقت الفعلي.

📖 طريقة إعداد حساب وجدول Supabase في دقيقتين (خطوات سهلة):
  1. سجل حساباً مجانياً على موقع supabase.com وأنشئ مشروعاً جديداً.
  2. من القائمة الجانبية ادخل على SQL Editor، ثم اضغط على زر «نسخ كود إنشاء الجدول» أعلاه والصقه هناك واضغط Run.
  3. ادخل على Project Settings -> API وانسخ Project URL و anon public key.
  4. الصق الرابط والمفتاح في الخانات أعلاه واضغط حفظ ثم اختبار الاتصال.
